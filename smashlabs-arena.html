Get Started

GET YOUR API KEYS

You need API keys to run live battles. Here's exactly how to get each one — takes under 5 minutes per provider.

01
Anthropic — Claude
Get Claude API Key
1. Go to console.anthropic.com
2. Sign up / log in
3. Click API Keys → Create Key
4. Copy the key — starts with sk-ant-
5. Add credits in Billing (~$5 to start)

Models: Claude Opus 4.6, Sonnet 4.6
ANTHROPIC_API_KEY=sk-ant-api03-xxx
02
OpenAI — GPT
Get OpenAI API Key
1. Go to platform.openai.com
2. Sign up / log in
3. Go to API Keys → Create new secret key
4. Copy the key — starts with sk-
5. Add payment in Billing → $5 min

Models: GPT-5.4, GPT-5.4 Thinking
OPENAI_API_KEY=sk-proj-xxx
03
Google — Gemini
Get Gemini API Key
1. Go to aistudio.google.com
2. Sign in with Google
3. Click Get API Key → Create API key
4. Free tier available ($0 to start!)
5. Starts with AIza

Models: Gemini 3.1 Pro, Gemini 3 Flash
GOOGLE_API_KEY=AIzaSy-xxx
04
Meta — Llama (via Groq)
Run Llama 4 for free
1. Go to console.groq.com
2. Sign up (free tier available)
3. Go to API Keys → Create
4. Llama 4 Scout + Maverick available free
5. Starts with gsk_

Models: Llama 4 Scout, Llama 4 Maverick
GROQ_API_KEY=gsk_xxx
05
Deploy to Vercel
Add keys to your site
Once you have keys, add them to Vercel so they work in production:

1. Open vercel.com → Your project
2. Go to Settings → Environment Variables
3. Add each key as a variable
4. Redeploy → done ✅

They'll be available as process.env.ANTHROPIC_API_KEY
// Next.js API route // pages/api/battle.js const key = process.env.ANTHROPIC_API_KEY
06
DeepSeek
Get DeepSeek API Key
1. Go to platform.deepseek.com
2. Sign up / log in
3. Go to API Keys → Create
4. Top up balance ($2 minimum)
5. One of the cheapest frontier APIs

Models: DeepSeek-V3.2, DeepSeek-R1
DEEPSEEK_API_KEY=sk-xxx
